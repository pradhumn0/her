# Birthday website

Files: index.html (page shell), style.css (look), content.js (YOUR TEXT), main.js (logic). Only edit content.js.

## Run locally
Double-click index.html, or run `python -m http.server` in this folder and open http://localhost:8000.

## Edit
1. Open content.js in any text editor (Notepad, VS Code).
2. Replace each [PLACEHOLDER] inside the quotes. Search for "[" to find them all.
3. Add more: copy one full line/block of an item (cards, story items, notes, envelopes) and paste it below, keeping the comma.
4. New paragraph inside one text: type \n\n. Straight quotes inside text break it; use ’ for apostrophes or put \ before a " mark.
5. Save and refresh the browser.

## Host and share (free)
Netlify: go to app.netlify.com/drop and drag the whole folder in. You get a link to send her.
GitHub Pages: create a repo, upload these files, Settings > Pages > deploy from main branch.
Tip: hide the link until her birthday; anyone with it can open it.

## Phone + desktop test checklist
- Opening screen fits without scrolling; button scrolls to the message.
- Every section reveals while scrolling, no sideways scroll.
- Timeline, cards (tap to expand), envelopes open/close.
- Cake: wish, blow out, relight, confetti.
- Letter opens and reads comfortably; surprises all respond.
- Finale confetti plays and Replay works.
- Turn on "reduce motion" in device settings: text still visible, no animation.
- Try longer text than the placeholders in every section.
